## النظرة الشاملة للمجموعات (Synergy)

### مجموعة المعايرة (Titration Group)
**الأدوات:** سحاحة + دورق مخروطي + جهاز pH
**التفاعل:** السحاحة تقطر → الدورق يستقبل ويتحرك السائل → الجهاز يرسم المنحنى
**الحالة:** ⚠️ يدوي — لا يوجد auto-align

### مجموعة التحضير والوزن (Preparation Group)
**الأدوات:** ميزان + دورق حجمي + ملعقة (Spatula)
**التفاعل:** وزن الملح → نقل إلى الدورق → إضافة ماء → حساب المولارية
**الحالة:** ✅ يعمل

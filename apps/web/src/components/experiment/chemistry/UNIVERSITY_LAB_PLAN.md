## الجزء 2: الأجهزة المتقدمة (Advanced Instruments)

### 2.1 مطيافية الامتصاص الذري (UV-Vis Spectrophotometer)
```
النطاق: 200–800 nm
الدقة: ±0.5 nm
الخواص:
  - λmax detection (peak finding)
  - Beer-Lambert law: A = εbc
  - Concentration determination from standard curve
  - Kinetics: absorbance vs time plots
التطبيقات:
  - تحديد تركيز Fe³⁺ بـ thiocyanate
  - KMnO₄ concentration
  - Enzyme kinetics
```

### 2.2 مطيافية الكتلة (Mass Spectrometer)
```
النطاق: 10–2000 m/z
الدقة: ±0.1 Da
الخواص:
  - EI (Electron Ionization)
  - Fragmentation patterns
  - Molecular ion peak (M⁺)
  - Isotope ratios
التطبيقات:
  - تحديد الصيغة الجزيئية
  - Structural elucidation
  - Gas analysis
```

### 2.3 مطيافية الأشعة تحت الحمراء (IR Spectrometer)

النطاق: 4000–400 cm⁻¹

الخواص:

  - Fingerprint region matching

التطبيقات:
  - Identification of unknown organic compounds
  - Purity checking
  - Reaction monitoring

### 2.4 جهاز التوصيلية (Conductivity Meter)

النطاق: 0.01 μS/cm – 200 mS/cm

الخواص:

### 2.5 مقياس الدوران البصري (Polarimeter)

### 2.6 مقياس اللزوجة (Viscometer)

## الجزء 3: تقنيات المختبر المتقدمة

### 3.1 المعايرة (Titration) — متقدم
```
أنواع المعايرة:
  ✓ Acid-base (strong/weak/polyprotic)
  ✓ Redox (permanganate, dichromate, iodometric)
  ✓ Complexometric (EDTA for Ca²⁺, Mg²⁺)
  ✓ Precipitation (argentometric: Mohr/Volhard/Fajans)
  ✓ Conductometric
  ✓ Potentiometric

الدقة المطلوبة:
  - Burette reading: ±0.01 mL
  - Endpoint detection: color change ±0.05 mL
  - Repeatability: RSD < 0.5%

الحسابات:
  - Molarity: M₁V₁ = M₂V₂
  - Equivalence point calculation
  - Indicator selection (pKa ± 1 = pH at endpoint)
  - Blank correction
  - Standard deviation
```

### 3.2 التقطير (Distillation)
```
أنواع التقطير:
  ✓ Simple distillation (Δbp > 25°C)
  ✓ Fractional distillation (Δbp < 25°C)
  ✓ Steam distillation (heat-sensitive compounds)
  ✓ Vacuum distillation (high bp compounds)
  ✓ Azeotropic distillation

المكونات:
  - Round-bottom flask
  - Heating mantle
  - Vigreux/packed column
  - Distillation head
  - Thermometer adapter
  - Condenser (Liebig/Graham)
  - Receiving flask
  - Boiling chips

الرسم البياني:
  - Temperature vs Volume
  - Theoretical plates calculation
```

### 3.3 الاستخلاص (Extraction)
```
أنواع الاستخلاص:
  ✓ Liquid-liquid extraction (separatory funnel)
  ✓ Acid-base extraction
  ✓ Multiple extractions
  ✓ Continuous extraction
  ✓ Solid-phase extraction (SPE)

الحسابات:
  - Distribution coefficient: K = C_org/C_aq
  - Extraction efficiency: %E = (1 - 1/(1+K(V_org/V_aq))ⁿ) × 100
  - pH-dependent extraction
```

### 3.4 إعادة التبلور (Recrystallization)
```
الخطوات:
  1. Dissolve in minimum hot solvent
  2. Filter hot (if insoluble impurities)
  3. Cool slowly (crystal formation)
  4. Filter cold (Buchner funnel)
  5. Wash with cold solvent
  6. Dry

المحسوبات:
  - Percent recovery
  - Melting point (purity indicator)
  - Optimal solvent selection
```

### 3.5 الترشيح (Filtration)
```
أنواع الترشيح:
  ✓ Gravity filtration (fluted filter paper)
  ✓ Vacuum filtration (Buchner funnel)
  ✓ Hot filtration
  ✓ Cold filtration
  ✓ Sintered glass filtration

الحسابات:
  - Filtration rate
  - Cake resistance
  - Specific resistance
```

### 3.6 التحليل الكروماتوغرافي (Chromatography)
```
TLC (Thin Layer Chromatography):
  - Rf = distance traveled by compound / distance traveled by solvent
  - Visualization: UV, iodine, staining
  - Column chromatography scaling

Column Chromatography:
  - Stationary phase selection
  - Eluent polarity gradient
  - Fraction collection
  - TLC monitoring

GC/HPLC:
  - Retention time matching
  - Peak area integration
  - Calibration curve
  - Limit of detection (LOD)
  - Limit of quantification (LOQ)
```

## الجزء 5: محرك التفاعلات الكيميائية (Reaction Engine)

### 5.1 أنواع التفاعلات
```
✓ Neutralization: H⁺ + OH⁻ → H₂O (ΔH = -57.3 kJ/mol)
✓ Precipitation: Ag⁺ + Cl⁻ → AgCl↓ (white)
✓ Redox: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O
✓ Complexation: Fe³⁺ + SCN⁻ → [Fe(SCN)]²⁺ (blood red)
✓ Gas evolution: CO₃²⁻ + 2H⁺ → CO₂↑ + H₂O
✓ Decomposition: 2H₂O₂ → 2H₂O + O₂↑ (catalyzed by MnO₂)
```

### 5.2 خواص التفاعل
```
| الخاصية | الوصف |
|---------|-------|
| **Stoichiometry** | موازنة المعادلة + حساب الكميات |
| **Rate law** | v = k[A]ⁿ[B]ᵐ |
| **Activation energy** | Ea = ... (Arrhenius) |
| **ΔH** | حرارة التفاعل |
| **ΔS** | التغير في الإنتروبيا |
| **ΔG** | ΔG = ΔH - TΔS |
| **Equilibrium** | K_eq = [products]/[reactants] |
```

### 5.3 التأثيرات البصرية
```
التفاعل → التأثير البصري:
  Neutralization → تغير لون المؤشر
  Precipitation → تكون راسب (عكر)
  Redox → تغير لون (purple→colorless)
  Complexation → تغير لون (yellow→blood red)
  Gas evolution → فقاعات + ارتفاع مستوى السائل
  Decomposition → فقاعات O₂ + اختبار العود
```
